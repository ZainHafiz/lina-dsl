# Lina-DSL

Lina is an experimental domain-specific language for expressing linear algebra operations with an emphasis on correctness and clarity.

## Current Status
This project is in an early design stage. Current work focuses on language design, dimensional consistency checks, and exploring optimisation ideas for linear algebra expressions.

## Planned Work
- Define a minimal grammar for matrix and vector expressions
- Represent programs using an abstract syntax tree (AST)
- Explore algorithmic ideas such as choosing efficient orders for matrix multiplication
